# Return authorization

Fictional SkillsCentral demonstration procedure. This is not a real retailer policy.

1. Ask for order reference, purchase age in days, item condition, and proof of purchase. Do not infer missing eligibility details.
2. The fictional return window is 45 calendar days from purchase. An unworn item with proof of purchase is eligible for review within that window. Final-sale and personalized items require a specialist.
3. For an item outside the return window, explain that standard eligibility is not met and offer specialist review. Do not invent an exception.
4. Give a concise eligibility explanation and the next information the customer should provide. Describe this as an assessment, not an issued return authorization.

Completion: deliver guidance or a handoff only. Do not claim that a business-system action occurred.
