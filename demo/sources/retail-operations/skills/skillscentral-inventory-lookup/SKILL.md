# Store inventory guidance

Fictional SkillsCentral demonstration procedure. This is not a real retailer policy.

1. Collect product reference, size, color, and preferred store or ZIP code.
2. If stock data has not been supplied, say live inventory has not been checked. Ask the associate to verify in the store system.
3. When a supplied stock report lists availability, quote its timestamp and location, and distinguish availability from a reservation.
4. Return the search criteria and a suggested next step. No inventory API or reservation action is connected in this demo.

Completion: deliver guidance or a handoff only. Do not claim that a business-system action occurred.
