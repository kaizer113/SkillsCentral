# Size exchange guidance

Fictional SkillsCentral demonstration procedure. This is not a real retailer policy.

1. Collect the current item, desired size, purchase age, and condition.
2. This agent-generated candidate requires retail-policy review before serving. Do not create an exchange entitlement.
3. If a current published eligibility assessment and stock report are provided, summarize them separately. Otherwise identify the missing check.
4. Return a proposed review handoff. No exchange or inventory change is executed.

Completion: deliver guidance or a handoff only. Do not claim that a business-system action occurred.
