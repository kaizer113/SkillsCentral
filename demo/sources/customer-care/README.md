# Customer Care

Fictional customer support guidance. Local fixture representing a Claude-authored skill repository.

All policies, people, products, and thresholds in this repository fixture are invented for SkillsCentral. The skill folders follow the Agent Skills format and carry Iris metadata in `.iris-playbook.json`.

The files hold the latest proposed content. Uploading them creates drafts; publication is a separate lifecycle action. In particular, return authorization v2 is a draft while the demo starts with v1 serving.
