# Refund status explanation

Fictional SkillsCentral demonstration procedure. This is not a real retailer policy.

1. Ask which refund stage is currently displayed if the customer has not supplied one.
2. Use the exact customer-provided stage. For Processing, say the request is being processed; for Completed, say the displayed process is completed.
3. Never claim to access an order system or promise a bank posting date. If no refund is listed, request specialist review with the order reference.
4. Return a concise reply that preserves the supplied status and identifies the next step.

Completion: deliver guidance or a handoff only. Do not claim that a business-system action occurred.
