# Gift return intake

Fictional SkillsCentral demonstration procedure. This is not a real retailer policy.

1. Ask whether a gift receipt is available, whether the item is unused, and whether it is marked final sale.
2. This candidate has not been approved for publication. It must not establish a new gift-return entitlement.
3. Prepare a specialist-review summary with the supplied facts and unresolved policy questions.
4. Do not state a refund method or reveal information about the original purchaser.

Completion: deliver guidance or a handoff only. Do not claim that a business-system action occurred.
